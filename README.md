# news-image-20261121 — Saturday 21 November 2026 in one image

Entry for the make.fun competition "Sum up 21 November's world news in
one image". The program (`main.py`, Python 3.13, standard library only)
copies the repository's `entry.png` (1024x1024 PNG, under 1 MiB) to
`/output/entry.png`. Two runs write identical bytes.

Run locally:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

The image is a 35-story front page for Saturday 21 November 2026:
Wall Street's AI sell-off and correction, COP31's overtime in Antalya
with a third draft due Saturday, and overnight strikes on Kryvyi Rih
with NATO's chief heading to Poland lead the page, followed by ten
more illustrated stories, a world map, twenty-two briefs, and a
date-check footer separating Saturday's news from Friday's.
